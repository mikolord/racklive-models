# Каталог моделей устройств для Rack Live

Готовые карточки устройств: фото на прозрачном фоне, размеченные порты (1, 2, 3…), границы приближения и, по желанию, 3D-модель.
В Rack Live: карточка устройства → «Вид» → «Из магазина» — модель подставляется одной кнопкой, вручную ничего размечать не нужно.

## Как добавить свою модель

1. Откройте **редактор**: <https://mikolord.github.io/racklive-models/>
2. Загрузите фото, уберите фон, отметьте порты, задайте зону приближения, заполните описание.
3. Скачайте `.zip` и нажмите «Предложить в каталог». Перетащите файл в заявку и отправьте.
4. Бот проверит модель. Если что-то не так, он напишет в заявке, что исправить. Если всё хорошо, откроется pull request, и владелец каталога его примет.

Нужен аккаунт GitHub. Писать в репозиторий напрямую могут только владельцы, остальные участвуют через заявки.

## Правила

| Что | Правило |
|---|---|
| Фото | PNG или WebP с **прозрачным фоном** (JPEG не подходит). Вокруг устройства — прозрачное поле. Длинная сторона 600–1600 px, файл до 600 КБ |
| Метаданные | EXIF и геопозиция удаляются (редактор делает это сам), в файле их быть не должно |
| Права на фото | Своё, CC0, CC BY / CC BY-SA (с автором и ссылкой), либо с разрешением правообладателя. Фото из магазинов и с сайтов производителей обычно защищены |
| Порты | Номер 1…256, не повторяются; рамка — в долях фото; тип: rj45, sfp, usb, power, console, other |
| Приближение | Прямоугольник внутри фото (`pzoom`) |
| 3D-модель | Формат `racklive-model` из «Сканера» Rack Live, проверяется теми же правилами, что и в приложении |
| В папке | Только `model.json`, `photo.webp` или `photo.png`, `model3d.json`. Ни кода, ни ссылок для скачивания |

Подробности для тех, кто правит файлы руками, — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Устройство репозитория

```
models/<производитель>/<id>/   model.json, photo.webp, model3d.json
docs/index.html                редактор (GitHub Pages)
tools/validate.py              проверка модели (те же правила, что в Rack Live)
tools/build_index.py           сборка index.json (список для «Магазина»)
tools/intake.py                приём заявок из Issue → pull request
tests/                         проверки проверяющего и редактора
index.json                     каталог; собирается автоматически
```

Проверка локально: `pip install pillow`, затем `python tools/validate.py` и `python tests/test_validate.py`.
