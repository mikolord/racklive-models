# Как добавить модель вручную

Обычно достаточно [редактора](https://mikolord.github.io/racklive-models/). Если правите файлы сами:

## Структура

```
models/<производитель>/<id>/
  model.json
  photo.webp          (или photo.png)
  model3d.json        (по желанию)
```

Имена папок — строчные латинские буквы, цифры и дефисы. `id` совпадает с именем папки.

## model.json

```json
{
  "format": "racklive-card", "version": 1,
  "id": "tp-link-t2600g-28mps", "vendor": "TP-Link", "model": "T2600G-28MPS", "kind": "switch",
  "title": "TP-Link T2600G-28MPS (v4)",
  "photo": {"file": "photo.webp", "license": "own", "author": "", "source": ""},
  "spots": [ {"n": 1, "x": 0.12, "y": 0.4, "w": 0.03, "h": 0.2, "kind": "rj45", "label": ""} ],
  "pzoom": {"x": 0.08, "y": 0.25, "w": 0.6, "h": 0.5},
  "model3d": "model3d.json"
}
```

- `spots`: `x`, `y` — центр порта, `w`, `h` — размер, всё в долях ширины и высоты фото (0…1).
- `pzoom`: `x`, `y` — левый верхний угол прямоугольника приближения, `w`, `h` — его размер, в долях фото.
- `license`: `own`, `CC0-1.0`, `CC-BY-4.0`, `CC-BY-SA-4.0`, `permission`. Для CC BY нужен `author`; для не своих фото — `source` (адрес `https://…`).
- Нужно хотя бы одно: `photo` или `model3d`.

## Что проверяет бот

Всё, что написано в README в таблице правил, плюс: лишние поля и файлы, дубли номеров портов, порты за краем фото, приближение за краем, подмена формата файла (не WebP под видом WebP), анимация, непрозрачный фон.
Предупреждения (не ошибки): порт стоит на прозрачном месте.

## Что бот НЕ делает

Не запускает ничего из присланного. Заявка — только данные. Скрипты, ссылки для скачивания и посторонние файлы отклоняются.

## Авторство и публикация

Отправляя модель, вы подтверждаете права на фото и согласны опубликовать данные модели в этом репозитории. Точки портов, зоны приближения и описание
публикуются на условиях лицензии репозитория (MIT, файл LICENSE), а фото остаётся на той лицензии, которую вы указали в заявке.
Владелец каталога может отклонить заявку, если фото нарушает чьи-то права, модель дублирует существующую или разметка неточна.
